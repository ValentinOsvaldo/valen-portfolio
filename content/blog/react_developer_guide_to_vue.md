# The React developer guide to Vue

React is the most popular frontend library to create user interfaces, but doesn't mean it's the best. On the other hand, Vue is a progressive framework for building user interfaces, and it's gaining popularity day by day. In this guide, I will show you how to migrate from React to Vue and take full advantage of Vue's features.

## What is Vue?

> Vue (pronounced /vjuː/, like view) is a JavaScript framework for building user interfaces. It builds on top of standard HTML, CSS, and JavaScript and provides a declarative, component-based programming model that helps you efficiently develop user interfaces of any complexity. - Source: [Vue official documentation](https://vuejs.org/)
